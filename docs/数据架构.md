# 本地数据架构和指标口径

本机网页看板通过本机服务读取数据库，也支持重新读取两份本地底表；命令行仍可导入。用户已授权将当前看板范围内的数据公开发布为 GitHub Pages 快照，访问者可直接查看和下载。

## GitHub Pages 浏览器版

页面打开时加载公开快照，在浏览器内的 Web Worker 中通过 Pyodide 执行 `pages/backend.py`，复用 `app.py` 和 `data_layer.py` 完成关联、筛选、汇总和 Excel 导出。页面和计算组件由 Pages 同源提供，首次加载需要下载。浏览器保存筛选条件，刷新数据仅重新加载已发布的快照。

`pages/build.py` 生成静态页面，`pages/make_snapshot.py --confirm-public` 从本地数据库生成公开快照，仅保留小学、初中、高中、自拼的处理记录和关联批次类型映射，并核对汇总、明细与筛选结果。快照包含维持计算与筛选所需的明细字段，任何人均可下载。部署到 `gh-pages` 分支后才更新网页；本机数据变化不会自动发布。原始 Excel 和本地数据库文件本身不发布。

## 数据读取和替换

`data_layer.py` 读取 Excel 的 `Sheet1` 实际单元格，兼容工作表尺寸标记不完整。日期支持 Excel 日期、`YYYY-MM-DD`、`YYYYMMDD`；空字符串和 `NULL` 等标记视为缺失。线索表的 `流量期次_学部`、`批次` 分别对应 `流量期次`、`线索批次`；例子数量字段支持 `例子量` 或 `例子数`，同时出现时拒绝导入。

页面点击“更新数据”后，`app.py` 读取项目目录的 `jingyinglirun_demo.xlsx`（经营）和 `xiansuoloudou.xlsx`（线索），两份表均校验成功才在同一事务中替换数据；缺少必要字段时提示文件名和缺失项，多余字段不参与数据处理。成功后按当前筛选刷新看板和选项。每份底表需先保存且包含所需全部历史，原文件不会被修改。

批次类型来自项目目录 `xiansuoleixin.xlsx` 的 `Sheet1`，按“批次”精确匹配关联明细的“线索批次”，使用“批次类型”列；未映射或批次缺失归为“其他”。每次看板查询和导出重新读取已保存的映射表，更新数据前也会校验；列缺失、映射行字段为空或同一批次对应不同类型时提示错误。映射不改变两份来源之间的五键关联。

每种来源分别做字段、日期及数值校验后，使用 SQLite 事务整体替换该来源的规范化数据和导入元信息；失败不改变已保存的来源。数据库记录文件名、SHA-256、UTC 导入时间，原始 Excel 不变。字段为空允许保留，不以零替代；日期或数值非空但无法识别时拒绝整次导入。默认数据库 `data/dashboard.sqlite3` 是本地业务数据，不应上传或提交。

## 粒度与关联

日期按每日新增；各源分别按 `日期 × 学部 × 流量期次 × 外呼池 × 线索批次` 汇总后关联。二级渠道忽略并参与合计。五个键均完整且相同才匹配；缺失键仅在本源内聚合，不与另一来源匹配。完整键两侧未命中以及缺失键均保留并标注状态：仅经营表有记录时显示“线索表未找到”，仅线索表有记录时显示“经营表未找到”；关联字段缺失时显示对应来源的“键缺失”。五键相同是候选关联，不保证两源覆盖范围或统计时点一致。

## 计算与边界

例子数量取经营例子量之和；看板明细只展示经营来源的例子量，经营数据缺失时显示“—”。线索例子量和两者在匹配键上的差异在数据层保留。接通转化率 = 线索例子量 / 同源 AI 接通数；有课例产 = 经营有课 GMV / 经营例子量；单例子结算成本 = sum(经营例子量 × 单例子结算成本) / sum(经营例子量)；北 A = sum(北A分子) / sum(经营例子量 × 单例子cac)。各指标按筛选结果重新汇总分子和分母，分母为零、缺失或必要输入不完整时不计算。聚合中任一必要输入缺失时，相应指标保持缺失，不忽略缺失行。总览包含筛选范围内各来源的全部记录；因覆盖范围可能不同，不计算总体跨源差异。

来源依据：知识库 `cards/指标口径卡.md`、`wiki/concepts/全链路分析口径.md`；本项目新表的跨源适配范围以上述已确认方案为准。数据在源表中的业务定义、日期及两源范围一致性仍需持续对账；匹配不等于业务口径已核实。

## 看板筛选和导出

看板、筛选选项、汇总和导出仅包含学部为小学、初中、高中、自拼的记录，其他或缺失学部不展示；原始数据仍保留。默认按日期倒序，同一天按小学、初中、高中、自拼排序，日期缺失排在末尾；学部筛选选项和手动按学部升序也采用此顺序。手动选择其他排序后以该排序为准。

学部、流量期次、外呼池、线索批次和批次类型支持多选：同一字段的选中值取并集，不同字段与日期条件取交集；未选择表示不限制该字段，缺失值仅在该字段未限制时保留。点击“查看结果”后应用筛选，核心指标按筛选后的全部明细重新汇总。

关联数据默认按日期、学部、批次类型汇总，展示例子量、接通转化率、有课例产、单例子结算成本和北A。明细先按五键关联并按筛选条件过滤，再按勾选的维度（日期、学部、流量期次、外呼池、线索批次、批次类型、关联状态）分组汇总；不勾选任何维度时，有数据则展示一条总计。未勾选的维度不再拆分结果；勾选或隐藏指标只控制显示。空的筛选结果不生成汇总行。关联状态仅在勾选时参与分组，关联发生在汇总之前，不因隐藏字段将原本未匹配的来源标记成已匹配。每组使用 `data_layer.py` 的 `summarize` 重算分子、分母及加权指标，缺失规则与总览一致；排序、分页在汇总后进行，结果数量为汇总行数。

`app.py` 的 Excel 导出复用已应用的筛选、勾选维度和排序，导出全部汇总结果而非当前页，列与页面勾选一致。数值保留计算结果，缺失值留空。页面总览、明细和 Excel 展示精度一致：接通转化率显示百分号后两位（如 0.05%），有课例产和单例子结算成本显示整数，北A按比值显示一位小数（如 1.1），不使用百分号；展示舍入不改变计算值。导出文件仅在本机生成，指标口径沿用上文规则。

## 趋势图

趋势图使用已应用的筛选条件，按日期和批次类型汇总筛选后的全部关联记录，与表格显示字段及分页无关。接通转化率、单例子结算成本分别复用上述来源和汇总公式；日期缺失的记录无法放在时间轴上，指标缺失或分母为零时不画点，缺失日期不跨越连线。日期较多时可在图表区域横向滚动。图表展示精度与表格一致。
